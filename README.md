# LLM-RAG-Projects

A collection of Retrieval-Augmented Generation (RAG), LLM, multimodal AI, agentic AI, and AI evaluation projects.

These projects demonstrate the development of AI applications from basic RAG APIs to enterprise document intelligence and agentic AI platforms.

## Projects

### 1. LLM RAG API

A foundational Retrieval-Augmented Generation application with an API-based architecture.

**Focus:** Document retrieval, embeddings, vector search, LLM generation, and FastAPI.

### 2. Audio RAG Assistant

A voice-enabled RAG assistant for asking questions about documents using audio input and AI-generated responses.

**Focus:** Speech processing, RAG, embeddings, vector search, and LLMs.

### 3. Multimodal RAG Assistant

A multimodal RAG application that works with text and visual information.

**Focus:** Multimodal document processing, embeddings, retrieval, vision models, and LLM generation.

### 4. Enterprise RAG Document Intelligence

An enterprise-oriented document intelligence platform for ingesting, processing, retrieving, and generating answers from organizational documents.

**Focus:** Document ingestion, parsing, chunking, embeddings, vector databases, RAG pipelines, LLM generation, and FastAPI.

### 5. Enterprise AI Generation & Evaluation Platform

An agentic AI platform for AI generation, tool usage, MCP-based integration, orchestration, and automated evaluation.

**Focus:** AI agents, MCP, tools, orchestration, RAG integration, LLM generation, evaluation, and quality metrics.
