# LLM-RAG-Projects

A collection of **Retrieval-Augmented Generation (RAG), Large Language Model (LLM), multimodal AI, agentic AI, MCP, and AI evaluation projects**.

These projects demonstrate the development of modern AI applications, progressing from foundational RAG APIs to multimodal assistants, enterprise document intelligence, and agentic AI platforms.

## Projects

### 1. LLM RAG API

A foundational Retrieval-Augmented Generation application with an API-based architecture.

The application demonstrates the core RAG workflow of document ingestion, chunking, embeddings, retrieval, and LLM-based response generation.

**Focus:** RAG, document retrieval, embeddings, vector search, LLM generation, and FastAPI.

### 2. Audio RAG Assistant

A voice-enabled RAG assistant for asking questions about documents using audio input and AI-generated responses.

**Focus:** Speech processing, audio input, RAG, embeddings, vector search, and LLMs.

### 3. Multimodal RAG Assistant

A multimodal RAG application that works with both textual and visual information.

**Focus:** Multimodal document processing, embeddings, retrieval, vision models, and LLM generation.

### 4. Enterprise RAG Document Intelligence

An enterprise-oriented document intelligence platform for ingesting, processing, retrieving, and generating answers from organizational documents.

**Focus:** Document ingestion, document parsing, chunking, embeddings, vector databases, RAG pipelines, LLM generation, and FastAPI.

### 5. Enterprise AI Generation & Evaluation Platform

A production-oriented agentic AI platform combining **LLM generation, RAG, AI agents, MCP-style tools, orchestration, reliability, evaluation, persistence, and observability**.

**Focus:** AI agents, agent orchestration, LLM provider routing, RAG integration, MCP-style tools, brand-aware generation, retry and fallback mechanisms, AI evaluation, PostgreSQL, Docker, Prometheus, Grafana, and automated testing.
